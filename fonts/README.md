# Font files

- `previews/` : file WOFF2 untuk pratinjau di browser (publik). Saat ini berisi 3 font placeholder berlisensi SIL OFL (Mrs Saint Delafield, Caveat, Yellowtail, subset Latin dari paket Fontsource).
- `ui/` : Instrument Sans (SIL OFL), font antarmuka.

**Jangan** taruh file master OTF/TTF di folder ini atau di repo publik. WOFF2 tetap bisa diunduh orang yang paham teknis; ini bukan DRM.
Ganti file placeholder dengan WOFF2 font asli Anda hanya jika lisensi mengizinkan web embedding.
